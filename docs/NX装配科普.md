# NX 装配科普（写给懂编程、不懂 CAD 的人）

> 目的：让你看懂"装配"这件事在 NX 里到底是怎么回事，
> 以及**为什么 Agent 之前做的装配是错的**、怎么才能让 Agent 自己发现装错。

---

## 一、先把术语翻译成你熟悉的东西

| CAD 里的词 | 你熟悉的东西 | 具体指什么 |
|---|---|---|
| **零件（Part / .prt）** | 一个源文件 | 一个 `.prt` 文件，里面是几何体。类似一个 class |
| **组件（Component）** | 某个 class 的**实例** | 装配体里 `new` 出来的一份零件。同一个零件可以装很多次（左右引擎舱就共享一个文件） |
| **装配体（Assembly）** | 组合模式 / 容器 | 一个 `.prt`，内容是一堆组件 + 它们的位置关系 |
| **工作部件 / 显示部件** | 当前编辑的文件 / 当前打开的文件 | 两个可以不同：你在编辑 A，但屏幕上显示的是 B |
| **引用集（Reference Set）** | 给别的模块看的接口/视图 | 零件在装配里"露哪些几何"。常用 `Entire Part`（全露） |
| **组件位置矩阵** | 一次坐标变换 | 4×4 变换（NX 里给 3×3 旋转 + 原点）。`GetPosition()` 读到的就是它 |
| **自由度（DOF）** | 还没被约束掉的变量 | 一个刚体在空间有 6 个自由度（3 平移 + 3 旋转）。加约束就是消自由度 |
| **装配约束（Constraint）** | 声明式的约束条件（像 CSS/布局引擎） | 你声明"这两个面贴合"，求解器算出坐标 |
| **重定位（Reposition）** | 手动拖 | 直接给坐标/朝向，不用约束 |
| **爆炸图 / 装配序列** | 可视化 / 动画 | 把零件炸开展示，或按顺序播放装配动作 |
| **干涉 / 间隙** | 碰撞检测 / 净空检测 | 两个零件是否互相穿透 / 是否离得太近 |

## 二、最关键的一件事：定位有**两种**做法，而我一开始选错了那种

### 做法 A：绝对定位（Absolute Positioning）—— 我现在用的

```
把每个零件的位置和朝向**算好**，直接告诉 NX：
  "S-II 放在 (0, 0, 441.9)，姿态是矩阵 M"
```

**像什么**：像你手写 CSS 的 `position: absolute; top: 441.9px; left: 0`。

- ✅ 简单、确定、可脚本化（批处理模式下也能用）
- ❌ **零件之间没有任何关系**。算错了就是错了，NX 不会告诉你
- ❌ 改一个零件的尺寸，别的零件**不会跟着动**
- ❌ 你要自己负责"对不对"

### 做法 B：装配约束（Assembly Constraints）—— **NX 的本职方式**

```
你不给坐标，只声明关系：
  "2-3 级间段的内圆柱面  与  S-II 顶端的外圆柱面   同心（Concentric）"
  "2-3 级间段的底面      与  S-II 的台阶面         接触（Touch）"
  "S-IC 底面             与  全箭基准面           对齐（Align）"
→ NX 的约束求解器**自己算出**每个零件该在哪
```

**像什么**：像 Flexbox / 约束式布局（Auto Layout、ConstraintLayout）。
你声明"这个按钮在父容器底部居中"，引擎算出像素。

- ✅ 声明式，改尺寸会自动重算（**参数化**）
- ✅ **约束不足 / 过约束，NX 会告诉你**（自由度没消完 = 还能动）
- ✅ 这才是 CAD 里"装配"的标准含义
- ❌ 批处理模式（`-auto=`）下能不能建约束，**还没验证过**

> **这就是我犯的根因**：我一直用做法 A，把"装配"当成了"算坐标"。
> 于是每个接头的对错全靠我的坐标对不对 —— 而我看不到图，只能瞎猜。

## 三、约束有哪些类型（常用的）

| 约束 | 作用 | 消掉的自由度 |
|---|---|---|
| **接触 / 贴合（Touch）** | 两个平面贴住，法向相反 | 1 个平移 |
| **对齐（Align）** | 两个平面共面且法向同向 | 1 个平移 |
| **同心（Concentric）** | 两个圆柱/圆孔共轴 | 2 个平移 |
| **距离（Distance）** | 两个面保持给定距离 | 1 个平移 |
| **中心（Center）** | 两个面对中 | 1~2 个平移 |
| **平行 / 垂直（Parallel / Perpendicular）** | 面或轴的关系 | 1 个旋转 |
| **角度（Angle）** | 固定夹角 | 1 个旋转 |
| **固定（Fix）** | 这个组件钉死不动（作为基准） | 6 个 |
| **胶合（Bond）** | 两个组件焊成一体 | 6 个 |
| **自动推断（Inferred）** | NX 看你拖到哪就猜约束 | — |

**装配的标准套路**：第一个组件用**固定**（它是基准），其余组件每个用 2~3 条约束定位到完全约束（6 个自由度全消）。

## 四、装配错误分三类，NX 各有对策

| 错误类型 | 俗称 | NX 里怎么查 | 接口 |
|---|---|---|---|
| **干涉** | 穿模、装不进去 | **干涉检查**（Interference Check）—— 算两两实体是否相交、相交体积多大 | `GeometricAnalysis.SimpleInterference.PerformCheck()` |
| **间隙不足** | 挨太近、装配时撞 | **间隙分析**（Clearance Analysis）—— 按给定净空值找过近的零件对 | `Assemblies.ClearanceAnalysisBuilder` |
| **约束不足 / 过约束** | 零件是松的 / 打架 | **装配导航器**看自由度；过约束会报冲突 | `Positioning.Constraint` / `ComponentPositioner` |

★ 这三样**全都能用 NXOpen（脚本）调用** —— 这就是你要的"让 Agent 能验证装配错误"的基础。

## 五、我们这次的坑：这是**3D 打印套件**，不是机械装配

土星五号这套 NASA 模型，本意是给人**打印出来用胶水粘**的。这类模型的设计习惯：

1. **每个零件的端头做成插接结构**（一个细脖插进对方的套筒/孔），
   目的是让打印件能对准、能粘牢 —— 而不是"两个端面贴平"。
2. **零件在文件里的坐标是"打印姿态"**，不是装配位置。
   实测这套 STL 的长轴区间从 −216 交错到 +437，完全是各干各的。
3. **零件尺寸不严格**（是给打印机的，不是给工程师的）。

所以：
- 用**包围盒端头**去对接 → 细脖全露在外面 → 你看到的"非常大的空隙"
- **朝向**必须按几何特征判断（哪端是塔尖、哪端带尾翼），不能默认"低坐标在下"
- **套接处必须允许重叠** → 但重叠到底是设计意图还是装错了？**只有干涉检查能分清**

### 我犯的错误清单（诚实记录）

| # | 错误 | 后果 |
|---|---|---|
| 1 | 用"包围盒端头"当对接面 | 级间大空隙 |
| 2 | 用"包围盒中心"当轴心 | 轴心不齐（零件上有导管/线槽会带偏） |
| 3 | 默认"低 Y 端朝下" | 逃逸塔尖朝下、S-IC 粗端朝上（**装反了**） |
| 4 | 只核对"Z 区间是否符合预期" | 预期本身就是错的，自己验自己 → 全过但实际错 |
| 5 | **没有做干涉/间隙检查** | 装反、重叠过头，**一个都没发现** |

第 5 条是最要紧的：**我的"验证"只是在验证"我算的坐标有没有被 NX 正确执行"，完全没验证"这样装对不对"。**

## 六、方案：给 Agent 装一套**分层校验**

```
第 0 层  坐标执行核对（已有）
          NX 实测位姿 == 我给的位姿          → 只证明"照做了"

第 1 层  ★ NX 干涉检查（要新增，最关键）
          两两实体 PerformCheck() → 谁插进了谁、插了多少
          区分：设计套接（细脖在套筒里）vs 装错（细杆捅穿了圆盘）

第 2 层  ★ NX 间隙分析（要新增）
          按净空值找过近的零件对

第 3 层  ★ 装配几何规则（要新增，离线可算）
          · 轴心偏差：每个组件相对全箭中轴的偏心量
          · 相邻级直径单调（火箭下粗上细）
          · 接缝跳变：相邻级在接缝处的半径差（可见台阶）
          · 空隙：相邻级 Z 区间是否接触

第 4 层  装配约束完整性（将来）
          每个组件自由度是否消完 / 是否固定
```

**关键**：第 1、3 层都能给出**可定位到具体零件对**的数值报告 ——
Agent 拿到"第 4 和第 5 号零件相交了 12.3 mm³，在 z=680 附近"，
就能自己改、自己验，**不需要长眼睛**。

## 七、想深入了解的话

在 NX 里打开一个装配体，按这些地方看：

| 看什么 | 位置 |
|---|---|
| 装配树、每个组件的约束和自由度 | **装配导航器**（左侧，装配环境下） |
| 加约束 | 菜单 **装配 → 组件 → 装配约束** |
| 干涉检查 | 菜单 **分析 → 装配分析 → 干涉** |
| 间隙分析 | 菜单 **分析 → 装配分析 → 间隙** |
| 爆炸图 | 菜单 **装配 → 爆炸图** |

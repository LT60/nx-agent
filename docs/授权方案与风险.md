# 授权方案与风险（含"该不该买拼多多上的 UG"）

## 0. 一句话结论

- **自己学习 / 开发用** → 用官方免费学生版，合法、免费、够用。
- **用户在厂里做生产** → 不能用破解版。这是**公司级**风险，而且责任很可能落到他个人头上。
- **拼多多上卖的，99% 不是软件，是"远程帮你装破解版"的服务。**

---

## 1. 先说一个反直觉的技术事实（免得你觉得我在讲大道理）

从**纯技术功能**看，破解版就是"完整商业版"，所以它：

- 能后处理（免费学生版不能）
- NXOpen 功能全开（学生版是否含 UGOPEN 我还没能确认）

也就是说，**单看功能，破解版看起来比学生版更适合我们这个项目**。这一点我不回避。

但它有一个具体的坑，会直接砸到我们的开发上：

- 破解通常靠**替换文件、改 hosts、伪造本地许可服务器、甚至 patch 掉某些 DLL/PYD**
- `NXOpen.pyd` 有可能被覆盖或 hook → **某些 API 会报奇怪的错，或者行为前后不一致**
- 装破解版往往要**关杀毒、开防火墙例外** → 环境变脏，出问题无法归因
- 结果：我们调试时会遇到"找不到原因"的诡异 bug，而最大嫌疑犯就是破解补丁

对做开发的人这是致命的：**你需要一个可信的基线环境。** 一个无法信任的运行环境，
会让所有排查工作失去意义。

---

## 2. 风险清单（按实际影响排序）

### 2.1 对工厂（最大）

- 使用盗版软件是侵犯著作权，企业面临**民事赔偿 + 行政处罚**
- 很多大客户（汽车、电子类）会对供应商做**软件正版化合规审计**，
  查出来可能影响供应商资格
- 西门子在中国有专门的正版化维权团队，模具 / 机械加工是重点行业
- 公司电脑上装了破解版，一旦被扫描到，暴露的是整个厂，不是一台机器

### 2.2 对用户个人（次大）

- 如果是在公司电脑上装、且用于生产，**出事时责任很可能落到装的人头上**
- "老师让买的"不等于"出事老师担"

### 2.3 供应链安全

- 破解包 / 激活工具是木马、挖矿程序、后门的高发载体
- "远程安装"意味着**对方远程控制他的电脑**
- 模具图纸是厂里的核心资产，泄露的代价远超软件本身的钱

### 2.4 对我们这个项目（技术）

- 见第 1 节：基线环境不可信，排查成本会翻好几倍

---

## 3. 那该怎么选

| 场景 | 用什么 | 理由 |
|---|---|---|
| **你自己的开发机** | 官方免费学生版（Designcenter Student Edition） | 合法、免费、够验证 MCP 链路和刀路 |
| 需要验证"出 NC 程序"那一段 | 30 天商业试用，或直接在用户真机验证 | 学生版不能后处理 |
| **用户的生产电脑** | **必须是厂里买的正版** | 风险在公司，责任在个人 |

---

## 4. 如果用户坚持要买，至少把风险降到最低

前提说清楚：**如果只是个人学习、验证用**，且你决定要做，那么至少做到：

1. **绝对不要装在厂里 / 公司的电脑上**，也不要接公司网络
2. **装在虚拟机里**（VMware / Hyper-V）。NX 在虚拟机里跑得慢，但完全够验证
   `run_journal`、`NXOpen` 导入、脚本重放这些开发环节
3. **不要用"远程安装"服务**，只要离线安装包，全程自己装
4. 装之前给系统做快照或备份；装完检查异常的进程、开机启动项、计划任务
5. **一台机器只装一套 NX。** 学生版会覆盖 `SPLM_LICENSE_SERVER` 环境变量，
   破解版也会改 hosts 和许可配置；两者混装会互相打架。
   而且 NX 卸载会连注册表一起清掉，很难恢复干净

---

## 5. 一个更省事的判断标准

问一句话就够了：**这套 NX 是用来学，还是用来生产？**

- **用来学** → 学生版，一分钱不用花
- **用来生产**（出图、出程序、上机床）→ 必须走公司正版。
  **这钱不该用户出，也不该用户担。**

---

## 6. 关于"老师让他们去拼多多买"

这在国内职校和培训班里非常普遍，通常是因为经费没有，或者"法不责众"的心理。
**这不是技术问题，是单位的授权缺失问题。**

- 如果用户**还在上学**、用的是学校机房 → 学校应该提供授权，让他问清楚学校有没有
- 如果用户**已经在厂里上班**、用的是厂里的电脑 → 那是厂里该解决的事

所以有一件事你需要先问清楚：

> **用户现在是学生身份用学校的电脑，还是已经在厂里上班、用厂里的电脑？**
>
> 这两种情况，风险归属和"该找谁"完全不同。

---

## 7. 一个额外提醒

免费的 NX Student Edition 和破解版，**不要装在同一台机器上**。
先装破解版再装正版 / 学生版，或者反过来，都会互相破坏。
如果你要两边都试，用不同的机器或虚拟机彻底隔离。

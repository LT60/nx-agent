### 装配坐标是怎么来的（**没有一个是手写的**）

这批 NASA STL 是**各零件独立建模姿态**，坐标互不相干 ——
实测长轴区间从 -216 交错到 +437，根本不是装配位置。所以：

1. `tools/saturn_layout.py` 解析 STL，量出每级的**轴向长度**；
2. **级序用土星五号公开级构**（S-IC 底/顶 → 1-2 级间段 → S-II → 2-3 级间段 →
   S-IVB → LEM 整流罩 → 服务舱 → 指令舱 → 逃逸塔）；
3. 每级落点 = 前面各级长度**累加**得出。

核验（`tools/check_saturn_stack.py`）：**10 级 Z 区间全部 0.00mm 偏差，
相邻级接缝 0.000mm，全箭 124.6 × 1286.6 mm**。

### 刀路：跑到哪一步了（**要说清楚**）

- ✅ **网格件（STL 小平面体）能被 NX CAM 接受**，6 道工序都算出了刀轨
  （`saturn.clsf` 43620 个刀位点）。
- ✅ **粗加工 `ROUGH_ALL` 是真的在切这个零件**：16227 个切削点，
  范围 X[-154,-47] Y[282,395] Z[-129,-56]，与零件实际位置吻合。
- ⚠️ **其余几道工序的切削区域还是模板自带的那套几何**，不是为这个零件编的。
  要拿到完整、正确的刀路，**下一步是真给这个零件编工序**（选刀、设切削区域）。
- ⚠️ 网格件算刀路很慢：6 道工序花了 3.5 分钟。

> 已知映射关系：**CLSF 坐标 = 零件坐标 − MSYS**（实测确认，MSYS=(100,50,111.6)）。

## ⭐ 刀路动画怎么看

浏览器打开后你会看到：
- **灰色半透明盒子** = 毛坯（加工前的整块料）
- **深色线框** = 最终零件（企业号）
- **彩色线条** = 刀具走过的轨迹，**按工序分颜色**
- **红色小球 + 竖线** = 当前刀尖位置（小球是刀尖，竖线是刀杆）

点 **「播放」** 就能看刀具从第一道工序走到最后一道。

### 这个动画能查出什么

| 看什么 | 怎么判断有问题 |
|---|---|
| **撞刀** | 刀具（红线）以非切削状态**穿过**零件实体 |
| **进刀过度** | 某一段轨迹颜色突然加深/重叠密集 = 同一处反复切 |
| **漏切** | 播完后零件某些面**没有**任何轨迹经过 |
| **抬刀高度** | 快移轨迹（不画的浅色段）离零件太近 = 有刮擦风险 |

右侧会实时显示：当前工序、刀尖坐标、刀径、已走点数、切削点数量。

> ⚠ **这个只画轨迹，不画材料被削掉的过程** —— 要看"料怎么被切掉"、
> 查撞刀，请用下面的 **`machining_sim.html`**。

## ⭐⭐ 材料切除仿真（查撞刀/漏切用这个）

**双击 `machining_sim.html`**。这个才是真正的 CAM 仿真：

- **灰色** = 毛坯（还没切到）
- **蓝色** = 已切到位
- **橙色** = 还剩料（**漏切**）
- **红圈** = 检测到疑似**撞刀**的位置

播放时能看到**材料一刀刀被削掉、企业号逐渐成形**。右侧自动报告：
撞刀几处、漏切多少格、当前到位率。

### 它是怎么算的（和工业软件同源）

用 **dexel 高度场**——把毛坯离散成 1mm 的小柱子，刀具扫过就把柱子削低。
VERICUT、NX 验证这类工业软件就是这么干的。

### ★ 精度与局限（重要，别当成权威结论）

| 参数 | 影响（实测） |
|---|---|
| 刀位点数 | 每工序 1500 点 → 到位率 **88%**；4000 点 → **99%**（抽稀会让"漏切"虚高） |
| 撞刀容差 | 0.02mm → 报 3066 处；**2mm → 48 处**（大部分是轻微插入的模型误差） |

**所以：这个仿真用来"看过程、找明显问题"很可靠，但精确判定请用 NX 自带的验证工具
或全量刀路。Agent 提供的是自动判据 + 置信度，不是最终裁决。**

### ★ 引擎舱为什么挪不动

`全长 288.6 m` 和 `引擎舱长 153.6 m` 都是**硬数据**，而**碟形前缘一定是船头、
引擎舱后端一定是船尾** —— 所以"引擎舱相对碟形的前后位置"是被锁死的，没有自由度。

真正能改的是**工程舰体**（公开数据只给了它的长度和直径，没给它在船上的位置）：
把它后移 `+10 → -20 m`，引擎舱伸出舰尾的长度就从 **131.5 m 降到 101.5 m**，
视觉上不再"甩在最后面"；同时偏导碟也落到了碟形后半部下方（更接近真机），
颈部也就能接到碟形后下方了 —— 三件事是同一个解。

### ★ 形状为什么改了（v2 是建模问题，不是 NX 问题）

用 `python tools/asm_silhouette.py <json>` 把 NX 几何渲染成 ASCII 三视图才看清：

### 为什么没有底板了

底板是**单件加工**留下的包袱：三轴刀从上往下切，零件必须"从底板往上长"。
装配里根本不需要它——零件之间是互相连接的：
颈部把碟形和工程舰体连起来，支架把引擎舱连到工程舰体上。所以这一版删掉了。

### ★ 加工姿态 ≠ 装配姿态

工程舰体和引擎舱都是**立着加工**（三轴刀够得着 / 车削），装配时**旋转 90° 横躺**。
这一步由 NX 的装配矩阵完成，实测读回的朝向是 `[1 0 0 | 0 0 1 | 0 -1 0]`。
另外支架和引擎舱各只有一个零件文件，被装了两次——改一次零件，两边都跟着变。

## 用 NX 打开（双击 enterprise_final.prt 即可）

### 第一步：打开后你会看到什么

一个**红色半透明的方块**罩着一个**灰色零件**：
- 灰色零件 = 企业号（底板 + 圆盘 + 两根柱子 + 小方块）
- 红色半透明方块 = **毛坯**（加工前的原材料，刀是从这块料上切出零件的）

**如果看不到模型**：按键盘 `Ctrl+F`（适应窗口），模型会缩放到合适大小。

### 第二步：看刀路（机床要走的路线）

1. 屏幕左侧找 **「工序导航器」**（英文叫 Operation Navigator）
   - 如果找不到：菜单栏 → 视图 → 显示工序导航器
2. 点它的顶部下拉框，选 **「程序顺序」** 视图
3. 会看到一棵树，展开后有 6 个工序：

| 工序名 | 干什么 | 有没有刀路 |
|---|---|---|
| ROUGH_ALL | 粗加工（把大部分料切掉） | ✅ |
| REST_MILL | 残料加工（粗加工没切干净的地方） | ✅ |
| PROFILING_BASE | 底部轮廓 | ❌（需要额外的几何指定，演示没做） |
| SEMI_FINISH... | 半精加工 | ✅ |
| FINISH_STEEP... | 精加工（陡峭面） | ✅ |
| FLAT_ZIGZAG | 平面精加工（往复走刀） | ✅ |

4. **右键任意一个工序 → 「重播」**（Replay）
   → 你会看到一把刀具沿着刀路移动，**这就是机床将要走的路线**。

### 第三步：看 3D 切除仿真（最重要的一步）

这就是"提前在电脑上看机床怎么把料切成零件"：

1. 右键 **ROUGH_ALL** → **「刀轨」→「3D 动态」**（3D Dynamic）
2. 弹出的窗口里按 **播放** 按钮
3. 你会看到：毛坯从一整块料，被刀具**一层一层切掉**，最后剩下企业号

**这个仿真就是给你检查用的**：
- 有没有**撞刀**（刀具撞到不该碰的地方，图上会看到刀具穿过零件）
- 有没有**进刀过度**（一刀切太深，留下明显的台阶）
- 哪些地方**没切到**（毛坯上还留着多余的料）

### 第四步：转个角度看看

- 鼠标**中键按住拖动** = 旋转
- **Shift + 中键拖动** = 平移
- **滚轮** = 缩放

转到底面看一下——你会发现底面是平的（因为它摆在机床工作台上，底面永远加工不到，这是正常的）。

## 这个演示验证了什么

整条 Agent 辅助加工的链路**全部自动化跑通**，人只负责最后看一眼：

```
① 从模板开始（NX 不支持从零创建 CAM）
        ↓  Agent 自动复制模板、清空旧几何
② 建模（底板→碟形→舰桥→引擎舱→合并成一个整体）
        ↓  每一步保存独立文件 = 你要的「阶段性文件」
③ 刀路生成（5 道工序，三轴铣床，中规中矩）
        ↓  重新指定了部件几何和毛坯
④ 仿真（刀路重播 + 3D 材料切除 + 截图）
        ↓
⑤ 人验收（你看图/NX，确认没问题）
```

## 为什么企业号是这个形状（答疑）

你原来担心"NX 只能减材制造，企业号合适吗"——**担心得对，但要改一处**：

- 真实企业号的两根引擎舱是**悬空**的（细支架连着），减材制造的刀具**伸不进悬空底下去**，铣不出来。那种形状只能铸造或 3D 打印。
- 所以这里做的是"**摆件版**"：所有形状都从底板**长出来**，没有悬空。这恰好就是模具厂天天干的活——**没有哪个模具零件是一刀铣出来的，全是分件加工再装配**。
- 你说的「**装配**」正是下一步的正路：把碟形、引擎舱、支架拆成 3~4 个独立零件，分别建模+编刀路，最后组装。每个零件反而更简单，且更贴近真实生产。单件链路已跑通，装配是下一个里程碑。

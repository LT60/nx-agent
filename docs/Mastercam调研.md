# Mastercam 调研报告

> 调研日期：2026-10-09
> 调研目的：给不懂 CAD/CAM 的用户讲清楚 Mastercam「是什么」+「怎么卖」
> 视角：**始终对照我们正在做的 NX-Agent 项目**——因为 Mastercam 是 NX 在 CAM 领域最直接的竞品。

---

## 0. 一句话结论

**Mastercam ≈ CAM 界的 "Windows/安卓"**：技术不是最强的，但**装机量最大、会用的人最多、后处理库最全**，
所以工厂爱用它。它是**纯 CAM 软件**（设计能力弱），靠**经销商（代理）卖**，**明文禁止外部程序驱动**——
这一条直接决定了：**它跟我们正在攻的 NX 是同一类墙，甚至更硬。**

## 1. 这是什么（基础框架 + 能干什么）

### 1.1 大白话定位

| 你的已知概念 | Mastercam 对应物 |
|---|---|
| 一门专精的 IDE（比如只做 Python 的 PyCharm） | Mastercam 是"只做加工编程"的专业软件 |
| 手机操作系统里的"安卓" | CAM 领域装机量第一，生态最大 |
| 一个 DLL 生态（谁都能写插件） | C-Hook / NET-Hook 插件机制 |
| 用官方 SDK + 经销商授权开发插件 | 第三方开发者计划（要申请、要登录） |

**和 NX 的根本区别**：NX 是「设计 + 加工」一体（CAD 强 + CAM 强），
Mastercam 是「**只管加工**」——零件模型通常是别人（NX/SolidWorks/CATIA）画好的，
导入 Mastercam 之后编程出刀路。**它是加工车间里的"专属工具人"。**

### 1.2 基本档案

| 项目 | 内容 |
|---|---|
| 开发公司 | **CNC Software, LLC**（1983 年由 Summers 三兄弟创立） |
| 母公司 | **Sandvik（山特维克）**——2021 年 8 月宣布收购，9 月 30 日完成，归入 Manufacturing Solutions 事业部 |
| 平台 | 仅 Windows（64 位，Win10/11） |
| 最新版本 | **Mastercam 2027**（2026 年发布）；**2026.R2** 于 2026-02-09 发布 |
| 版本节奏 | ★ **2026 年起从"一年一版"改为"一年两版"**（.R2 半年度更新） |
| 核心能力 | 2D~5 轴铣削、车削、车铣复合、多轴加工；建模准备、刀路生成、仿真、验证 |
| 语言 | 多语言（含中文） |
| 授权类型 | 商业专有软件 |
| 市场地位 | **CIMdata 年度 CAM 市场报告连续多年排名第一（使用最广泛的 CAM 软件）** |

### 1.3 技术基础框架（三层）

这是用户问的"基础框架"，我拆成三层讲，对照 NX 更清楚：

**第一层：几何内核（CAD 部分）**
- Mastercam 的 CAD 内核是自己攒的（历史包袱，从 1983 年 2D 时代演化而来），
  **建模能力明显弱于 NX**（NX 用 Parasolid，是业界顶级内核）。
- 但**强在导入**：能吃 STEP / IGES / Parasolid / SolidWorks / CATIA 等各种格式，
  因为它的用户本来就"模型是别人给的"。

**第二层：CAM 内核（核心资产，也是它真正的护城河）**
| 技术 | 说明 |
|---|---|
| **Dynamic Motion**（动态运动） | 2010s 中期起主打：按材料啮合量动态调整刀路，**降低切削时间 + 减少刀具磨损**。类似 NX 的自适应铣、HyperMill 的 iMachining 概念 |
| **后处理库** | ★ **500+ 种机床标准后处理，开箱即用率约 90%** —— 这是全行业最全的 |
| **仿真验证** | 2026.R2 起 **GPU 加速**：实测原本 90 分钟的验证 → **22 分钟**（约 10x） |
| **多轴策略** | 2023 起 Unified Multiaxis；2026.R2 加牛鼻刀自动倾斜、4 轴侧刃铣（Swarf）改进 |
| **Verification** | 碰撞检测、材料去除分析 |

**第三层：扩展 / 自动化接口**（★ 对我们最重要）

| 机制 | 语言 | 要不要编译 | 我们能不能用 |
|---|---|---|---|
| **C-Hook** | C/C++（MFC） | 要 | 需要完整 SDK，**要联系经销商** |
| **NET-Hook** | C# / VB.NET / J# | 要 | 同上，需要 SDK + 开发者资格 |
| **VBScript** | VBScript | 不用 | 内置编辑器，最简单 |

★ **关键事实（决定成败）**：
- **有官方命令行入口**：`Mastercam.exe "xxx.dll"` 可让插件随启动运行，
  加 `/exit` 参数则「跑完就退出」。VBS 也能挂在命令行上。
- ★★ **但官方明确回答："能不能不开 GUI 后台跑？—— NO。"**
  （CNC Software 的 Roger Martin 在官方论坛原话，99% 确定不行）
  → **和 NX 一模一样：必须有个 GUI 会话，脚本寄生在里面。**
- ★★★ **更狠的一条**：官方文档说 **"NET-Hook 跑在 Mastercam 内部，
  所以『NET-Hook 自己没法启动 Mastercam』"**，而且
  **命令行上的 DLL 会被当成 C-Hook（C++）而不是 NET-Hook**——
  要启动 NET-Hook 得先用 VBS 或 C-Hook 去"间接"拉起来。
  → **比 NX 的坑还多一层。**
- **SDK 获取**：需要**加入 Mastercam 3rd Party Developer 计划**
  （好处是能拿预发布版 + C-Hook SDK），**要登录 myMastercam**——
  也就是说**得先有正版账号 / 走经销商**。

### 1.4 能到什么效果（实际能力边界）

**能做**：2D 铣削、3D 曲面、多轴联动、车铣复合、钻孔攻丝、电极加工（有专门模块）、
去毛刺（Deburr 插件）、刀路仿真验证、直接输出 G 代码（**后处理是它的强项，不像 NX 学生版被锁**）。

**2026 年的新东西（值得注意）**：
- **Mastercam Copilot**（2026.R2 首次正式发布）：**AI 助手 + 语音控制编程**。
  - 支持约 **200 种刀路类型**，能"根据口头描述建机床组和工序"。
  - 说 **"Copilot"** 激活**免手操模式**（Active Listening）。
  - 能改进给 / 转速，**带确认提示保证安全**。
  - 还能搜 myMastercam 视频库，返回带时间戳的教程链接。
  - → ★ **这就是"官方在做我们想做的事"**：Agent 辅助 CAM 编程。
    但它做的是「**厂内现场语音助手**」，不是「**脱离软件的外部 Agent**」。
- **EverPath Technology (Beta)**：2026 年 4 月在 MACH 2026 展出，号称刀路创建的"重大重构"。
- **GPU Simulation**：仿真提速约 10x。
- **Blum 激光对刀仪集成**：Fanuc / Siemens / Okuma / Heidenhain / Mazak / Makino 主流系统。

### 1.5 和 NX 的对比（用户最关心的实操差异）

| 维度 | Mastercam | Siemens NX CAM | 谁赢 |
|---|---|---|---|
| **入门门槛** | 低（新手 1 个月可独立编多轴） | 高（流程长，设置多） | **Mastercam** |
| **会不会用的人多** | ★ 全行业最多（技校 / 大专主打教它） | 少，多在大型企业 | **Mastercam** |
| **找工作难度** | 招 Mastercam 程序员比招 NX 容易 | 招聘池小 | **Mastercam** |
| **后处理库** | 500+，开箱即用 90% | 强但需定制，学习 1~2 周 | **Mastercam** |
| **CAD 一体** | 弱，要导入模型 | ★ 设计+加工同源，改模型刀路自动更新 | **NX** |
| **复杂多轴 / 模具** | 广度好，深度稍逊 | 深（可变轴、曲面轮廓铣） | **NX** |
| **二次开发 / API** | C-Hook / NET-Hook，要开发者计划 | NXOpen（C++/C#/Python/Java），社区活跃 | **NX**（明显） |
| **企业级 PLM** | 无 | Teamcenter 数字主线 | **NX** |
| **外部自动化驱动** | ★ 官方明确说不行 | 学生版不行；商业版可行 | **打成平手（都是墙）** |

**行业共识（来自多方对比文章）**：
- Mastercam = 中小工厂 / 单件小批量 / 通用加工 / 招人容易
- NX = 航空航天 / 汽车 / 模具型腔 / 设计加工一体 / 企业级
- **它俩在模具厂里经常同时存在**：设计用 NX，加工用 Mastercam，或反之。

## 2. 运营方式（商业模式）

### 2.1 卖法：**经销商（代理）制**，不是网上直接买

- 官方口径：**"无论工业还是教育用途，第一步都是联系你的 Mastercam 经销商"**。
- 这是它和 Autodesk（Fusion 直接订阅）最大的不同——**渠道驱动**。
- 收购后还有个明显趋势：**Sandvik 在持续收购各地的经销商，改成直营**。
  - 2025-02 收购 OptiPro 的 CAD/CAM 业务、MCAM Northwest、ShopWare
  - 2025-03 收购 Barefoot CNC、CAD/CAM Solutions、CamTech、CIMCO 部分业务
  - 2025-11 收购 QTE Manufacturing Solutions
  - 2026-01 收购瑞典/挪威的 AME（改名 Mastercam Sverige）
  - 2026-02 收购 MLC CAD Systems 的 CAM 业务
  - 2026-03 收购加拿大 In-House Solutions（改名 Mastercam Canada）
  - 2026-07 收购 Mastercam India
  - → ★ **"去中间商化"**：渠道还在，但总部在收编。

### 2.2 授权模型：**模块化 + 永久授权 + 维护费**

| 模式 | 说明 |
|---|---|
| **永久授权（Perpetual）** | ★ 买断，长期资产归属。这是它吸引工厂的关键 |
| **维护 / 订阅（Mastercam CONNECT）** | 年度维护费，**买了才能持续更新** |
| **模块化付费** | ★ 多轴、车铣复合、高级仿真等要**单独加钱买模块**，不是一价全包 |

**Mastercam CONNECT（维护计划）包含**：
- 所有版本更新（含半年度的 R2 + beta 计划）
- **原本要收费的插件免费**（例如 Deburr 去毛刺插件）
- **Mastercam University 网课无限看**（备考认证）
- 知识库 + 论坛
- Tech Exchange（示例文件、刀具库、可定制后处理下载）

**价格参考（不能只信官网，要看真实成交）**：
- 官方**不公开报价**，全靠经销商报。
- ★ 从中国政府采购公告里挖到了**真实成交价**（这才是硬数据）：
  | 采购方 | 版本 | 单价 |
  |---|---|---|
  | 江苏阜宁中专 | Mastercam 2025 教育版（单机） | **¥30,000** |
  | 会昌中专 | Mastercam 2021 教育版 | **¥16,000** |
  | 江苏盱眙中专 | Mastercam 2022 教育版（6 节点） | **¥23,333/节点** |
  | 诸暨技师学院 | Mastercam 2023 教育版单机 | **¥24,400** |
  | 诸暨技师学院 | Mastercam 2023 教育版网络版 | **¥14,000/节点** |
  | 大连世赛基地 | Mastercam 2022 教育版 | **¥27,870/套** |
  → **教育版单机授权大致在 ¥1.6 万 ~ 3 万区间**（随年份上涨，越新越贵）。
  → **工业版明显更贵**（要多轴、车铣复合模块的话，通常数万到十几万）。
- 公开评测的说法：**模块化定价"奖励想清楚需求的工厂，但会惹恼想要一价全包的人"**。

### 2.3 教育战略（★★ 对用户最相关）

- Mastercam 是 **"世界上使用最广泛的 CAD/CAM 教育解决方案"**（官方自述）。
- ★ **它在技校 / 大专 / 职业院校的渗透率极高**——所以"招人容易"这个优势是**结构性**的，
  一代一代学生出来就只会 Mastercam。
- 有专门的 **教育版**、**Mastercam 制造日（Manufacturing Day）**、**师资培训**、
  **免费学生/教师资源**、认证体系（备考 Mastercam University）。
- "快速零件系列（Rapid Part Series）"：给老师的项目式课程。
- → 用户如果有大专学籍/在职证明，**走教育版渠道可能比工业版便宜得多**
  （但教育版通常不能商用，要问清楚）。

### 2.4 生态 / 合作关系
- **DMG MORI 合作**：把 Mastercam 后处理随机床一起打包卖（2025-12 宣布）。
- **ModuleWorks 合作**：Mastercam 和 Cimatron（都是 Sandvik 旗下）是 GPU Simulation 首发伙伴。
- **CloudNC 合作**：CAM Assist（AI 生成刀路）插件**同时支持 Fusion / Mastercam / Siemens NX**——
  2025-09 时全球已有 1000+ 机加工车间在用。★ **"AI 插件"这一层是跨平台的，不绑死在谁身上。**
- **CIMCO** 后处理和探测产品被收编改名 **Mastercam Probing**。

## 3. ★ 对 NX-Agent 项目的直接启示（重点）

这一节是本报告的真正价值——把调研结论映射到我们自己的项目。

### 3.1 好消息：我们的技术路线被"官方认证"了
- Mastercam 官方的话说得很直白：**"不开 GUI 跑？NO"、"NET-Hook 跑在 Mastercam 内部，
  自己启动不了它"**。
- → 说明**"脚本必须寄生在已启动的 GUI 会话里"这件事，不是 NX 学生版的特殊限制，
  而是整个专业 CAM 软件的行业共识**。
- → 我们的架构（`ugraf.exe -auto=<journal>` 让脚本寄生在真 GUI 里）**是正解**，
  换任何软件都是这个套路。

### 3.2 坏消息：想"换 Mastercam 绕过 NX 的墙"是**行不通的**
| 我们的痛点（NX 学生版） | Mastercam 是什么情况 |
|---|---|
| 外部驱动被锁（3615094 / 3600045） | ★ **官方文档明确禁止**，比 NX 更直白 |
| 后处理不能出 G 代码 | ✅ **Mastercam 后处理是强项**，这里它赢 |
| 不能建 CAM 设置（batch 模式） | 需实际验证，但同样受限于"必须 GUI 会话" |
| 没有正版 | 要买，教育版 ¥1.6~3 万；SDK 还要开发者计划 |

**结论**：**换软件不能解决问题，只会换一面墙**。而且 NX 我们已经有 1 年授权 + 全套工具链，
重新趟 Mastercam 的坑（学 API、搞 SDK 资格、买授权）**成本远高于收益**。

### 3.3 但有一个信号必须重视：**Mastercam Copilot**

这是**「Agent 辅助 CAM 编程」的商业化落地**，官方 2026 年正式发布。它告诉我们：
- ✅ 这个方向**是被行业认可的**，不是我们瞎想。
- ⚠️ 但它做的是**"厂内语音助手"**（人在软件前说"把进给调到 800"），
  **不是"脱离软件的外部 Agent"**。
- ★ **我们的差异化定位因此更清晰**：
  | | Mastercam Copilot | 我们的 NX-Agent |
  |---|---|---|
  | 交互形态 | 语音 / 文字下命令 | 自然语言对话 |
  | 人是否必须在 NX 前 | **是** | ★ **不需要**（用户只跟 Agent 说话） |
  | 干的事 | 改参数、建工序组、查教程 | 建模 + 编刀路 + 仿真 + 出图 + 离线校验 |
  | 知识来源 | 内置 + 视频库 | 可沉淀师傅的工艺参数（`cutting_defaults.json`） |
  → **我们做的是"更外面一层"的东西**，不是和 Copilot 抢活。

### 3.4 一个务实的观察
- 用户厂里**很可能两个软件都有**（模具厂常见组合）。
- 如果哪天用户真的要用 Mastercam，**我们的 NX-Agent 方法论（查 API → 反射 → 试错 → 离线校验）
  是可以平移的**——因为坑是同一类（GUI 会话、脚本寄生、后处理、授权）。
- 但**现在没必要开第二条战线**。先把 NX 这条路走通、交到用户手上。

## 4. 还需要确认的（未验证项）

| # | 待确认 | 怎么确认 |

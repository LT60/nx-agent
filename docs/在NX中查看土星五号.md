# 在 NX 中查看土星五号：模型 / 装配 / 刀路 操作手册

> 前提：所有文件在 `output/enterprise/` 目录。**`saturn_parts/` 子目录是装配的零件源，必须和 `saturn_v_from_nx.prt` 放在一起（保持原目录结构），移动时把整个 `enterprise` 文件夹一起拷。**

## 一、先说结论（对照表）

| 你想看的 | 在哪看 | 怎么打开 |
|---|---|---|
| 9 件装配成品 | NX 交互模式 | 打开 `saturn_v_from_nx.prt` |
| 每个零件的加工刀路 | NX CAM 或离线图 | 打开 cam_base 部件 / 看 `tp_*.png` |
| 切掉材料的动画 | 浏览器 | 双击 `saturn_sic_sim.html` 等 |
| 全流程总览 | 浏览器 | 双击 `nx_agent_showcase.html` |

## 二、打开装配（最重要的步骤）

**必须用「交互模式」启动 NX，不要用 `-auto=` 机器人模式。**
原因：机器人模式的显示层被实测证明不可靠（数字对、画面零件散开）——这正是之前搁置的那个问题。交互模式（平时手动打开 NX 的方式）没有这个毛病。

1. 平时怎么打开 NX，就怎么打开（开始菜单 / SSC 里启动都行）。
2. File → Open → 选 `output/enterprise/saturn_v_from_nx.prt`。
3. 你会看到一个 999mm 高的火箭装配体，9 个组件。
4. 装配导航器（左侧 Assembly Navigator）里可以逐个勾选/隐藏组件；右键组件 → Blank/Show 可以单独看某一件。
5. 快捷键 Ctrl+F（Fit）把整个模型缩放到窗口中间。

注意：装配文件本身**只存"引用 + 位置"**（程序员类比：装配 = 一份 manifest，不内联数据），所以 `saturn_parts/` 里的 10 个零件 .prt 必须在原位置，否则零件打不开。

## 三、查看刀路（三种方式，由易到难）

**方式 A（最省事，推荐先看这个）**：离线渲染图 `tp_sic.png`、`tp_sii.png`、`tp_coupler.png`。
这是把 NX 输出的真实刀位点（CLSF）叠画到零件上的图，每一道工序一种颜色。不依赖 NX，显示永远正确。

**方式 B（在 NX 里看刀路仿真，推荐）**：打开 CAM 部件文件
- `saturn_cam_base.prt`（第三级 S-IVB 的 6 道工序）
- `cam_base_sic.prt`（第一级）
- `cam_base_sii.prt`（第二级）

★ 2026-10-11 起，三个部件里的 6 道工序**刀路已经生成并保存进文件**（AskPathExists 实测 18/18 = True），打开即可直接回放，不需要重新计算。

操作步骤（NX 2606 中文界面）：
1. File → Open 打开任一 `cam_base*.prt`。
2. 若当前在建模模块：左上角「文件 → 启动 → 加工」进入加工模块（或 应用模块 → 加工）。
3. 左侧资源条点开**工序导航器（Operation Navigator）**，程序顺序视图里有 6 道工序
   （ROUGH_ALL 粗加工 / REST_MILL 剩余铣 / PROFILING_BASE 轮廓 / SEMI_FINISH… 半精 / FINISH… 精加工 / FLAT_ZIGZAG 平面）。
4. **看刀轨（静态线框）**：右键某道工序 → 「刀轨 → 编辑显示」，或直接双击工序，图形区显示彩色刀轨线。
5. **看刀路回放（刀具动画）**：右键工序 → 「刀轨 → 回放（Replay）」——NX 会显示刀具沿刀路移动的动画，可用进度条拖动、单步。
6. **看材料去除仿真（3D 动态，最接近"看着它被铣出来"）**：
   右键工序 → 「刀轨 → 可视化（Verify / 3D 动态）」→ 选「3D 动态」选项卡 → 点「播放」——
   NX 会用毛坯块实时显示材料被刀具一层层切掉的过程（这是 NX 自己渲染的，不是离线图）。
   播放控制里可调速度；「比较」选项能把结果和设计件对比。
7. 想一次看全部：在工序导航器最顶上的 PROGRAM 节点（父组）上右键 → 刀轨 → 回放/可视化，会按顺序连播全部 6 道。

⚠️ 学生版限制提醒：刀路能看、能回放、能 3D 动态仿真、能出 CLSF，但**不能后处理成 G 代码**（MOM License 不允许），这是学生版硬限制，不是操作问题。
⚠️ 若打开后工序前是黄色感叹号（提示需要重新生成）：右键工序 → 生成（Generate）即可，交互模式下生成不受批处理限制。

**方式 C（看刀位源文件）**：`saturn.clsf` / `saturn_sic.clsf` / `saturn_sii.clsf` 是纯文本的刀位数据（GOTO x,y,z 逐行），可以用记事本打开——这不是给人看的，是给后处理器吃的"刀路原料"。在 NX 里可通过 制造 → CLSF 编辑器 加载预览，但不如方式 B 直观。

⚠️ 学生版限制提醒：刀路能看、能重播、能出 CLSF，但**不能后处理成 G 代码**（License 不允许），这是学生版硬限制，不是操作问题。

## 四、材料去除仿真（浏览器直接看）

双击打开（不需要 NX）：
- `saturn_sic_sim.html` — 第一级铣削，材料被一层层切掉
- `saturn_sii_sim.html` — 第二级
- `saturn_sim.html` — 第三级

这是用刀位点数据模拟的"材料被刀切掉"的过程，纯浏览器渲染。

## 五、一句话总结

- **看装配**：交互模式打开 `saturn_v_from_nx.prt`。
- **看刀路**：先看 `tp_*.png` 三张图，想交互就在 NX 里打开三个 `cam_base*.prt` 按 Replay。
- **看动画**：三个 `*_sim.html`。
- **总览**：`nx_agent_showcase.html`。
